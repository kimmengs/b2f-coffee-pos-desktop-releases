# B2F Coffee POS Desktop — Releases

Download and auto-update channel for the B2F Solution coffee POS Windows app.

- Installers are published here by the `Desktop Release` workflow in the
  private source repo (`kimmengs/b2f-coffee-pos`).
- Installed POS clients check this repo for updates automatically.
- Get the latest installer from the [Releases page](https://github.com/kimmengs/b2f-coffee-pos-desktop-releases/releases/latest).

This repository intentionally contains no source code.
